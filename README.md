Reduction of ZTF force photometery for general use.

The implementation is straight forward, make sure to clone the ZTF_FP_Reduction.py and fp_lc_workflow.ipynb, then provide the name of the ZTF force photometery file and the name of the object.
In the forth cell you can choose the window that serves the baseline interatively (use the square on the left to zoom into the full light curve).
